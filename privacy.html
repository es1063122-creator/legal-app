4. 제3자 서비스

RiskWise는 앱 기능 제공을 위해 다음과 같은 제3자 서비스를 사용할 수 있습니다.

  • Google Firebase Authentication: 사용자 로그인 및 인증
  • Google Firebase Firestore: 사용자 설정, 사용량 및 앱 데이터 저장
  • Google Firebase Cloud Functions 또는 Cloud Run: AI 상담 기능 처리
  • Google AdMob: 광고 제공
  • Google Play Billing: 인앱 결제 및 구독 관리
  • OpenAI API 또는 기타 AI 서비스: 사용자가 입력한 상담 내용에 대한 답변 생성
